简历我也不怎么会写，但是你必须清楚一件事情：要简洁、精炼且对口。

## 简历

### 个人信息

- 姓名
- 学历
- 手机号
- 证书
- GitHub 账号
- 微信号
- 求职意向
- 个人照片

### 自我评价

简单描述相关经历和意向即可。

### 技能树

根据你学过的内容，把所有相关技术栈写出来。

### 项目经历

包括工作经历和比赛经历，重点注意：

- 一定要选择最相关的经历；
- 在于精，不在于多；
- 说明自己的职责；
- 列出使用的技术栈；
- 概括项目特点，例如你用了什么、实现了什么。

---

## 作品集

作品集是简历中项目经历的延伸，主要解决简历上写得不够具体的问题。

每个项目可以按照下面的结构展示：

1. 项目名称；
2. GitHub 链接；
3. 项目的具体优势。这里直接写优势即可，因为简历上已经有项目描述。

展示时注意：

- 图文并茂；
- 排版紧凑；
- 有看点；
- 可以从“相比于其他方案……”的角度展开；
- 要体现出自己的思考。
